# Mostakbal
Le Portail Officiel de Cyber Souveraineté Numérique de la République de Mostakbal centralise l'accès aux services citoyens d'État civil et d'identité. Cette solution web permet la gestion sécurisée des demandes de CNIe, passeport biométrique, acte S12 et naturalisation, garantissant la protection des données et le suivi des usagers.
